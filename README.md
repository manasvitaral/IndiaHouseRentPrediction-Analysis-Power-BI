# India House Rent Prediction Dashboard

## 📌 Project Title / Headline

**India House Rent Prediction & Rental Market Analysis Dashboard**

An interactive data analytics dashboard that explores India's residential rental market by analyzing house rents across major cities, property sizes, furnishing types, bedroom configurations, and localities. The project provides actionable insights into rental trends and housing patterns to support data-driven decision-making.

---

## 📖 Short Description / Purpose

The **India House Rent Prediction Dashboard** is designed to analyze and visualize rental housing data from multiple Indian cities. The dashboard helps users understand how factors such as location, furnishing status, property size, and number of bedrooms influence rental prices.

Through interactive visualizations and filtering capabilities, stakeholders can identify rental market trends, compare city-wise pricing, and uncover factors that significantly impact house rents.

---

## 🛠️ Tech Stack

* **Power BI** – Dashboard Development & Data Visualization
* **Microsoft Excel / CSV** – Data Source & Data Preparation
* **Power Query** – Data Cleaning and Transformation
* **DAX (Data Analysis Expressions)** – Measures, KPIs, and Calculations
* **Data Modeling** – Relationships and Aggregations

---

## 📂 Data Source

The dataset used in this project was obtained from **Kaggle** and contains residential rental property listings from major Indian cities.

The dataset includes attributes such as:

* City
* Locality
* House Type / BHK
* Monthly Rent
* Property Size (Sq. Ft.)
* Furnishing Status
* Number of Bathrooms

**Source:** Kaggle – [*House Rent Prediction Dataset*](https://www.kaggle.com/datasets/pranavshinde36/india-house-rent-prediction)

This dataset was used for exploratory data analysis, rental market trend identification, and dashboard creation to understand the factors influencing house rents across different Indian cities.

# 📊 Features & Highlights

## 1️⃣ Business Problem

The rental housing market in India is highly dynamic, with prices varying significantly across cities, localities, property sizes, and furnishing levels.

Potential tenants, landlords, real-estate analysts, and investors often face challenges in:

* Understanding fair rental pricing.
* Comparing rents across different cities.
* Identifying high-demand housing segments.
* Analyzing factors that influence rental values.

Without a centralized analytical view, deriving meaningful insights from rental data becomes difficult.

---

## 2️⃣ Goal of the Dashboard

The dashboard aims to:

* Analyze rental price distribution across major Indian cities.
* Compare rental trends based on furnishing status.
* Examine the relationship between property size and rent.
* Identify cities with the highest and lowest average rents.
* Explore housing inventory by property type and bedroom count.
* Enable interactive filtering for detailed market analysis.
* Support rental price prediction and decision-making.

## 📈 Business Impact & Insights

### Key Insights Derived

✅ Mumbai records the highest average rental prices among analyzed cities.

✅ Property size shows a positive correlation with rental value.

✅ Furnished properties generally command higher rents compared to semi-furnished and unfurnished units.

✅ Rental prices vary significantly across cities even for similar bedroom configurations.

✅ Semi-furnished properties represent a substantial portion of available inventory, indicating strong market demand.

✅ Certain localities offer larger property sizes at comparatively lower rents, creating attractive opportunities for tenants.
